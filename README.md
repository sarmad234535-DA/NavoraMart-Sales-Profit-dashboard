## 📌 Project Overview

NavoraMart Sales & Profit Dashboard is an Excel-based data analysis project designed to analyze sales and profit performance across different categories, products, years, months, and states.

The project demonstrates the complete workflow from raw data preparation to an interactive business dashboard.

---

## 🎯 Business Problem

The objective of this project is to analyze sales performance and identify patterns in:

- Sales and profit over time
- Product performance
- Category performance
- Geographic sales distribution
- Monthly sales trends
- Number of sales transactions

The dashboard allows users to interact with the data using slicers for **Category, Year, and Month**.

## 🔄 Project Workflow

**Raw Data → Data Cleaning → Analysis → Dashboard → Insights**

### 1. Data Cleaning

The raw dataset was cleaned and prepared for analysis.

The cleaning process included:

- Identifying data quality issues
- Correcting inconsistent values
- Standardizing data
- Preparing the dataset for analysis

The raw and cleaned datasets are included in the `data` folder.

### 2. Data Analysis

The cleaned data was analyzed to understand:

- Sales performance
- Profit performance
- Product performance
- Category performance
- Monthly trends
- Yearly trends
- State-level performance

### 3. Dashboard

An interactive Excel dashboard was created with:

- Total Sales KPI
- Total Profit KPI
- Profit by Year
- Sales Transactions by Year
- Sales by Category
- Top 5 Products
- Sales by Month
- Sales by State

Users can interact with the dashboard using **Category, Year, and Month slicers**.
